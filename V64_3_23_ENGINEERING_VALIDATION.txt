Final V23 algorithm contract
----------------------------
Main: evidence-local Regret-Coherent Reliability (RCR).
- deployment-admissible incumbent preserved by default;
- no learned admissible-incumbent->anchor veto;
- replacement population is TRAIN-only, final-guard-admissible, frozen support-positive,
  frozen scalar incumbent-dominance-positive alternatives;
- local risk uses fixed K={32,64}, inverse-distance weighted candidate-vs-incumbent TRAIN
  teacher-improvement mean minus one weighted standard error, with minimum across scales;
- evidence-local main uses the frozen 18-dimensional evidence-reliability view;
- signed main requires the actual equal-mean scalar/profile ranking score >0, but does not
  require profile dominance to be independently positive (not V21 hard consensus);
- zero local-risk boundary is fixed; no validation threshold/K/view-weight tuning;
- all-flagged structural delegation and final certificates/guards unchanged.

Transition conditioning role
----------------------------
Transition-local RCR is a controlled ablation, not the main mechanism.
Group-balanced metric blocks are evidence(18), transition semantics(21), geometry(20), each
contributing an average squared standardized distance.
On the uploaded TRAIN artifact with the fixed scene cross-fit:
- evidence-local signed RCR: 5/5 folds path-safe, selected teacher-improvement sum +9.846293;
- transition-local signed RCR: 3/5 folds path-safe, aggregate sum +14.413167.
The transition view has higher aggregate TRAIN sum but inferior fold stability; it cannot
rescue a failed evidence-local main. It is absorbed only if it is incremental on both fresh
A/B blocks.

Runtime / speed
---------------
V23 launcher reuses V22's completed TRAIN transition frontier when present, avoiding the
uploaded replay cost of 1786s (~29.8 min). If absent it recreates the frozen TRAIN artifact
once. Fitter stderr is captured with `2>&1 | tee` so future TRAIN STOP reasons are visible.
Fresh token filtering remains before NPZ deserialization.
The ~1455x18 evidence-memory local lookup benchmark is ~0.50 ms for 26 candidate queries on
this CPU environment after cache warm-up; this is only a microbenchmark, not an end-to-end
planner-latency claim.

Leakage / data audit
--------------------
- Runtime current-scene inputs: frozen EAF/frontier values, selected-evidence attribution,
  safety/final-guard state and frozen fitted/local-memory artifacts.
- The local memory stores TRAIN runtime features and TRAIN teacher-improvement targets as an
  offline nonparametric reliability readout. It never queries current validation/test teacher
  values and it consumes no extra planner-interface evidence.
- No validation/test teacher signal enters memory/config selection.
- V22 selected no fresh validation tokens, therefore V23 design exclusion remains exactly
  the prior 4700 inspected validation tokens.
- Uploaded TRAIN frontier token manifest: 3000 unique tokens. Existing 4700 validation design
  exclusion tokens have overlap=0 with these 3000 TRAIN tokens.
- V23 fresh selection is scenario identity + fixed SHA256 only and produces independent
  A500/B500 blocks; the launcher hard-checks TRAIN/fresh overlap=0 before evaluation; no pooled rescue.
