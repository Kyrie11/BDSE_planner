2) Mandatory training-graph smoke test
--------------------------------------

SMOKE_TRAIN_SCENARIOS=1024 \

Do not start the full pipeline unless the smoke output reports every check PASS,
including L_certified_residual_winner, residual uncertainty, correctable-scene
support, and the x5/x2 optimizer LR groups.

5) Optional machine-specific open-loop concurrency benchmark
------------------------------------------------------------
Run after the full pipeline has produced calibrated configs and a frozen best
checkpoint. It evaluates a short paired subset with 1, 2, and 3 workers/GPU.

export CANDIDATE_CONFIG="$OUT_ROOT/calibration/v58_csip_bfar_dbap_candidate_calibrated.yaml"
export LOCAL_CONFIG="$OUT_ROOT/calibration/v58_csip_bfar_dbap_local_control_calibrated.yaml"
export FOUNDATION_CONFIG="$OUT_ROOT/calibration/v58_csip_bfar_dbap_foundation_control_calibrated.yaml"
export CANDIDATE_CKPT="$OUT_ROOT/train/bdse_v58_csip_bfar_dbap.best.pt"
export BENCH_ROOT=outputs_v58_open_loop_concurrency_benchmark
export BENCH_SCENARIOS=120
export WORKER_SETTINGS="1 2 3"
bash BENCHMARK_V58_OPEN_LOOP_CONCURRENCY.sh
cat "$BENCH_ROOT/benchmark_summary.json"

Use the fastest setting as OPEN_LOOP_WORKERS_PER_GPU for later ablations. Do not
choose solely by CPU core count; prediction is GPU-bound and excess same-GPU
workers can reduce throughput.

6) Frozen paired reactive CL20
------------------------------
Use a separate output root and the already frozen checkpoint/configs. Do not
retrain or recalibrate between non-reactive and reactive evaluation.

export SOURCE_OUT_ROOT="$OUT_ROOT"
export REACTIVE_OUT_ROOT=outputs_v58_csip_bfar_dbap_reactive_cl20_2gpu_v1

SOURCE_OUT_ROOT="$SOURCE_OUT_ROOT" \
REACTIVE_OUT_ROOT="$REACTIVE_OUT_ROOT" \
GPUS=0,1 \
CL_WORKERS_PER_GPU=4 \
bash RUN_V58_REACTIVE_CL20.sh

If RUN_V58_REACTIVE_CL20.sh is not needed on the first run, the equivalent is to
copy the frozen calibrated candidate/local/foundation configs to a separate
output root and execute run_v58_csip_bfar_dbap.sh with
CL_CHALLENGE=closed_loop_reactive_agents for all three systems on identical tokens.

7) V58 acceptance criteria before CL100
---------------------------------------
- strict protocol PASS;
- minimum metrics PASS;
- candidate-local teacher-match gain > 0, then target >= +0.005;
- pair-full residual gain >= +0.005;
- beneficial residual rate > harmful residual rate;
- no deployed residual flip below the required evidence certificate;
- valid proposal-conditional residual/dual certificate statistics;
- paired NR-CL20 and R-CL20 have identical token hashes across all controls;
- no collision/TTC/drivable-area regression.
