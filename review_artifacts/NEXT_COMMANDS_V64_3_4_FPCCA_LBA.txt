6. Full-run causal decision after the winner finishes
-----------------------------------------------------
Inspect, in this order:

A. Acquisition
  teacher_exact_winner_flip_critical_recall_topm
  teacher_exact_winner_flip_critical_recall_selected
  proposal_decisive_atom_recall
  critical-boundary frontier representability

B. Fixed-budget interface
  dense_vs_hab_topm_dense_value_match
  dense_vs_selected_budget_dense_value_match
  budget_vs_pair_full_match
  evidence_certificate_fraction
  fallback_would_trigger_rate

C. Value/action ceiling
  pair_full_interface_action_match
  local_pair_full_interface_action_match
  teacher_action_match
  paired teacher regret vs matched foundation

D. Closed loop
  only after Protocol PASS; use paired candidate/local/foundation CL20 on exactly
  the same scenario tokens. CL100 remains blocked until competitive open-loop and
  CL20 evidence are both positive.

Decision rules:

1) critical Top-M does not improve in any clean screen
   -> acquisition representation is still the blocker. Do NOT modify B/M/DA-EPC.

2) critical Top-M improves, selected critical does not
   -> only then revisit B16 allocation/tie-breaking; keep B=16.

3) critical Top-M AND selected improve, but pair-full/candidate teacher match is flat
   -> acquisition is fixed enough; switch the next algorithm to atom->action /
      pair-boundary value representation. Do not stack more proposal losses.

4) open-loop teacher match/regret improves, CL20 is flat/worse
   -> switch to candidate dynamics / interactive prediction / replanning.

7. Important protocol note from uploaded V64.3.3
------------------------------------------------
The uploaded full runs have dense_runtime_query_decision_match=0.997 (<0.999), so
formal closed loop was correctly blocked. In the three mismatched AP-WCCA scenes,
raw dense/runtime query features are exactly identical and neural score max error
is <0.001; this is a near-tie numerical reproducibility issue, not cache/query
provenance drift.

Do NOT lower the 0.999 protocol threshold and do NOT mix a numerical-matmul change
into the acquisition ablation. If 0.997 repeats for the selected V64.3.4 winner,
run a separate strict numerical-parity engineering experiment after the algorithm
choice is frozen.
