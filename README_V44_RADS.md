# v44 RADS: Regret-Aware Any-Budget Deployment Supervision

v44 addresses a training/deployment mismatch in the v30 checkpoint used by
v41-v43. The v30 training run has four epochs, while its predicted selector
starts at epoch six. Consequently, action-level pair supervision uses oracle
certificate masks throughout training and never optimizes the selector path
used at inference.

## Changes

1. **Deployment-aligned curriculum.** Epoch 0 retains the oracle certificate as
   a short warm-up. Epochs 1-11 use masks generated by the exact runtime MARS
   selector.
2. **Any-budget supervision.** Each deployment-supervised batch optimizes
   budgets 8, 16, and 24 with weights 0.75, 1.5, and 0.75. This trains one model
   to remain decision-sufficient across a budget curve rather than overfitting
   only B=16.
3. **Robust regret weighting.** Teacher regret of the currently selected action
   is normalized per scene, transformed by log1p, and clipped before weighting
   action loss. High-consequence deployment errors receive more weight without
   allowing heavy-tailed teacher costs to destabilize training.
4. **Schedule validation.** Training now fails fast when the run would end
   before the predicted selector receives action supervision. Oracle-only runs
   require an explicit ablation flag.
5. **No combinatorial runtime repair.** v44 uses the fast MARS control selector,
   not v41-v43 deployment coreset search. The goal is to learn the deployed path
   rather than recover it with expensive per-scene subset search.

## Recommended sequence

```bash
export BDSE_TRAIN_CACHE=/path/to/bdse_train_v2
export BDSE_VAL_CACHE=/path/to/bdse_val_v2

V30_CKPT_IN=outputs_v30/train/bdse_v30_pmvrbsr.best.pt \
OUT_ROOT=outputs_v44_rads \
RUN_MODE=train_open_loop \
GPU=0 \
bash run_v44_rads.sh
```

Run CL20 only after the 1000-scenario open-loop comparison passes the following
minimum checks versus the frozen v30/MARS control:

- teacher action match increases by at least 2 absolute points;
- median and p90 teacher regret do not regress;
- winner/rival pair-sign accuracy increases;
- evidence sufficiency increases materially;
- p95 planning latency is measured and remains below the chosen deployment
  target.

Then:

```bash
export NUPLAN_ROOT=/path/to/nuplan
RUN_MODE=cl20 V44_CKPT=outputs_v44_rads/train/bdse_v44_rads.best.pt \
OUT_ROOT=outputs_v44_rads GPU=0 bash run_v44_rads.sh
```
